# Yâren — Tek Sayfa Web Sitesi (Case Study)

Her fincanda ortak bir hikâye.

## Çalıştırma
1. `index.html`, `style.css` ve `script.js` dosyalarını aynı klasöre koy.
2. `index.html` dosyasına çift tıkla; tarayıcıda açılır. Derleme veya kurulum gerekmez.
3. (İsteğe bağlı) Yerel sunucu: `npx serve .` veya `python -m http.server`.
4. Canlı yayın için klasörü Netlify Drop, Vercel veya GitHub Pages'e yüklemek yeterli.

> Yazı tipleri (Fraunces, Inter) Google Fonts'tan yüklenir; internet yoksa Georgia / sistem fontuna düşer.

## Kısa açıklama (başvuru formu için)
Siteyi yalnızca HTML, CSS ve saf JavaScript ile, hiçbir kütüphane kullanmadan yaptım. Açılışta kahve çekirdekleri yukarıdan düşüp sekerek bir yığın oluşturuyor, ardından perde kalkıp navigasyon ve hero alanı animasyonla beliriyor. Fincan görselleri ve ahşap doku SVG ile CSS gradyanlarından çizildi; buhar, kayan bant ve kaydırınca beliren kartlar gibi detaylar eklendi. İletişim formunda boş alan ve e-posta biçimi kontrolü var, geçerli gönderimde başarı mesajı gösteriliyor; mobil menü ve `prefers-reduced-motion` desteği de mevcut. Kodun yazımında yapay zekâ (Claude) yardımı aldım; yapıyı, renkleri ve içeriği gözden geçirip düzenledim.
